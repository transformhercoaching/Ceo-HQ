# CEO HQ

Upload all files in this folder to the root of a GitHub repository, then enable GitHub Pages.

## GitHub Pages setup
1. Create a new public repository called `ceo-hq`.
2. Upload every file in this folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the **main** branch and `/root`.
6. Save and wait a minute or two.
7. Open the Pages link GitHub gives you.
8. In Chrome, tap the three dots and choose **Install app** or **Add to Home screen**.

Your saved data remains stored in that browser/device for now.
